About this preserved website

This is a local restoration of KevlarX / Flaming Head Software's Cell Block A website, originally at www.netidea.com/cell. These notes were added on October 15, 2026; they are not part of the historical website.

The original pages retain their wording, colors, spacing, fixed image sizes, and animated navigation. This is a composite of surviving captures, not a complete snapshot of any single day. The archive has gaps, so it is not a pixel-perfect reproduction.

Sources

  • Main page — October 13, 1999.
  • Download page — November 9, 1999.
  • Screens page — May 17, 2000.
  • Links page — June 10, 2000.
  • Most graphics come from 2000 captures. The full-size first and third screenshots come from the site's later pics/ directory (November 2001), and the Flaming Head Software logo comes from March 2002. They are surviving site assets; their identity with the missing 1999 copies cannot be established.
  • Original Cell Block A 1.3 installer — October 24, 2001 capture. The download link now points to this local, unmodified file. It was not executed.

Documented substitutions

  • cellblocka.gif and download.gif: text headings occupy the original image dimensions. Their original artwork was not recovered.
  • e-mail.gif: the original link's email address is shown as text.
  • box1.gif and toroid1.gif: the surviving alternate Main and Download icons are reused. The current page remains unlinked, as in the original.
  • The unavailable server-side visitor counter is omitted; no count is invented.
  • Image alternative text, document language, and a small link to these notes are added.

External links and the historical email address are retained as historical content. Only outbound links require an internet connection; pages, illustrations, screenshots, navigation, and the installer work locally.

Preservation record

The manifest records source URLs, requested captures, retrieved byte lengths, SHA-256 hashes, and comparison with the archive's CDX SHA-1 digests. Some replay payloads differ from their CDX digest; this is recorded rather than silently treated as a verified match. Selected HTTP capture metadata is retained too.

Unmodified replay payloads live in ../_archive/original/, including additional surviving graphics from the later design. See README.md for the offline rebuild and verification command. The website and installer retain their original authorship; this restoration does not assign them a new software license.
