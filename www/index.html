Two versions of the original Flaming Head Software website.

1999Green on black. Animated navigation, original story, renders, and screenshots. 2001The blue redesign. Image-button navigation, a new gallery layout, and user-created maps.

Both versions include Main, Screens, Download, and Links pages. The archived version 1.3 installer is shared; the 2001 site also includes the original map pack.

This selection page is a modern addition. The historical pages are restored from mixed-date Internet Archive captures. Missing artwork and other changes are documented in the 1999 notes and 2001 notes.
